# Splunk SOC Foundations

## Overview

This repository documents my hands-on learning and practical work with Splunk as part of my SOC Analyst preparation.

The focus is on understanding Splunk fundamentals, data onboarding, log types, SPL queries, datasets, dashboards, and troubleshooting.

## Repository Structure

### 01. Environment Setup

Installation and initial configuration of Splunk for hands-on practice.

### 02. Splunk Fundamentals

Core Splunk concepts including indexes, sourcetypes, sources, hosts, events, and fields.

### 03. Data Onboarding

Hands-on process of ingesting log files and configuring indexes, sourcetypes, timestamps, and field extraction.

### 04. Log Types

Individual documentation and analysis of different security-relevant log types such as DNS, HTTP, FTP etc.

### 05. SPL

Practical learning and documentation of Splunk Search Processing Language (SPL) commands and queries.

### 06. Datasets

Datasets used for practicing SPL queries and analyzing security events.

### 07. Dashboards

Dashboards and visualizations created during the learning process.

### 08. Troubleshooting

Common issues encountered during Splunk setup, data onboarding, searching, and analysis.

## Learning Objectives

* Understand the fundamentals of Splunk.
* Set up and configure a Splunk environment.
* Learn how data is organized using indexes, sources, and sourcetypes.
* Ingest and verify different types of log data.
* Understand security-relevant log sources.
* Develop practical SPL query skills.
* Practice analyzing security events using real and sample datasets.
* Create dashboards and visualizations.
* Document troubleshooting and lessons learned.

## Tools Used

* Splunk Enterprise
* Splunk Search & Reporting
* SPL (Search Processing Language)
* BOTS v3 Dataset
* Sample Security Log Datasets

## Progress

This repository is continuously updated as I progress through my Splunk and SOC Analyst learning journey.
