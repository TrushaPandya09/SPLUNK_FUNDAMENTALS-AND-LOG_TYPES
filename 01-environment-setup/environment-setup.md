Set up and configure a local Splunk environment for learning Splunk fundamentals, practicing SPL queries, ingesting log data, and performing security event analysis.

## 1. Splunk Installation

Splunk Enterprise was installed on the local system to create a hands-on environment for learning and practicing Splunk.

### Installation Steps

1. Download Splunk Enterprise.
2. Run the Splunk installer.
3. Accept the license agreement.
4. Select the installation directory.
5. Create the administrator account.
6. Complete the installation.
7. Start Splunk.
8. Access the Splunk Web Interface.

### Installation Path

```
C:\Program Files\Splunk\etc\apps
```

### Splunk Web Interface

```
http://localhost:8000/en-US/account/login?return_to=%2Fen-US%2F
```
